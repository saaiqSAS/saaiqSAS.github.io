Course Details


The LX-1 (Introduction to Linux) online training course covers the very basics of Linux, virtual machines and cyber security.

This course is designed for absolute beginners and is delivered through live online sessions conducted via an online meeting platform. The total instructional time is up to 5 hours, spread over a period of one week. The course is taught by saaiqSAS.

Course Topics Include (but are not limited to):

  • General structure of a computer system.
  • Basic concepts of operating systems.
  • Understanding the concept of open-source software.
  • Understanding what Linux is and the different methods to set it up.
  • Understanding virtualization technology and how it is used.
  • Installing Linux on a virtual machine.
  • Using the Linux graphical interface.
  • Using the Linux command-line interface.
  • Understanding the structure of commands, including parameters and inputs.
  • Introduction to basic office and graphics software on Linux.
  • Installing and updating software packages using the Linux terminal.
  • Basic concepts of cybersecurity and penetration testing.
  • Introduction to OSINT and OSINT tools.
  • Introduction to Linux network tools.
