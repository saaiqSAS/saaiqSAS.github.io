About Course


The WD-1 (Introduction to Website and Web Application Development) online course provides a beginner-friendly introduction to modern web development. It covers the fundamental concepts of HTML, CSS, and basic JavaScript, allowing students with no prior programming experience to understand how websites are built and function on the Internet.

The course is designed for absolute beginners and is delivered through live online sessions conducted via an online meeting platform. The total instructional time is generally up to 10 hours, spread across a period of two weeks. The course is instructed by saaiqSAS.

Course Topics Include (but are not limited to):

  • Basic concepts of operating systems, web browsers, web servers, and how websites operate on the Internet
  • Understanding file extensions and basic file extension manipulation for web development tasks
  • The basic structure and format of an HTML document
  • Common HTML elements including html, body, footer, p, h1, input, br, link, a, img, div, and b
  • Fundamental CSS concepts and commonly used styling properties
  • Understanding and applying hexadecimal color codes
  • Using CSS hover effects for interactive design
  • Introduction to JavaScript syntax, data types, variables, operators, decision making, and functions
  • Basic manipulation of the Document Object Model (DOM) using JavaScript
  • Managing HTML, CSS, and JavaScript in separate files and organizing project directories
  • Basic web page design principles and introductory user interface (UI) design
  • Introduction to publishing websites using third-party web hosting services
